# Agent Browser

Run `agent-browser skills get core` before interacting with a page.
Use the CLI's version-matched guide for snapshots, element references, waiting, and session cleanup.
Use a named, isolated session, and keep any sign-ins in the agent's own profile.

Use `cua-driver` for native applications and desktop automation.
For Chrome platform guidance and browser verification, use `modern-web-guidance`.

Source: [agent-browser v0.43.0](https://github.com/vercel-labs/agent-browser/tree/v0.43.0), Apache-2.0.
