Reviewing a retry policy

Decide how long background jobs should retry before asking an operator to intervene.

Plan Design options Architecture PR walkthrough Operator docs

Implementation plan

  1. Record when a job first fails so each attempt shares the same deadline.
  2. Retry transient failures for 30 seconds. Send permanent failures directly to the failed jobs list.
  3. Verify that restarting the worker preserves the original deadline.

How a failure moves through the worker

  1. 1. WorkerRecords the first failure and sends its type to the retry policy.
  2. 2. Retry policyCompares the failure type and elapsed time with the retry deadline.
  3. 3. QueueSchedules another attempt or moves the job to failed jobs.

When should I retry a job manually?
